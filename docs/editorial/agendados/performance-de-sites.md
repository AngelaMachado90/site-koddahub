# O que deixa um site mais rápido?

Performance não é apenas uma nota de ferramenta. Uma pessoa percebe quando a página demora a mostrar o que veio buscar, quando um botão responde tarde ou quando o layout muda enquanto tenta tocar na tela.

## Comece pela jornada

Abra a página no celular e identifique a primeira informação importante. Uma imagem grande acima do texto pode atrasar essa resposta; uma fonte que carrega tarde pode mover títulos e botões. Priorize conteúdo necessário, dimensões conhecidas para imagens e JavaScript apenas quando a interação exigir.

Os Core Web Vitals usados pelo Google observam carregamento, resposta a interações e estabilidade visual por meio de LCP, INP e CLS. Esses números orientam diagnóstico, mas devem ser lidos junto com tarefas reais e dados de usuários. Melhorar uma métrica sem facilitar o contato ou a leitura pode não resolver o problema principal.

## Meça e repita

Compare mobile e desktop, páginas leves e páginas com imagens. Corrija primeiro recursos que afetam mais visitas e tarefas importantes. Depois da alteração, confira se a navegação continua acessível e se o conteúdo não foi removido apenas para melhorar a pontuação.

Uma melhoria sustentável combina carregamento previsível, conteúdo claro e interface que responde no momento esperado.
